# 本项目常用命令备忘

以下四条均为只读查询，不修改资源。使用自己的 AWS 控制台 CloudShell 身份，不记录 Access Key、Cookie 或完整邀请链接。排错时先看输出，不需要背参数。

## 查函数 URL 与授权类型

```bash
aws lambda get-function-url-config --function-name cj-photo-api --region ap-northeast-1 --query '{AuthType:AuthType,FunctionUrl:FunctionUrl}' --output json --no-cli-pager
```

预期 AuthType 为 AWS_IAM。网址用于 CloudFront 回源，前端仍请求当前网站的 /api/photos。

## 查运行时、处理程序、内存和超时

```bash
aws lambda get-function-configuration --function-name cj-photo-api --region ap-northeast-1 --query '{Runtime:Runtime,Handler:Handler,Memory:MemorySize,Timeout:Timeout,State:State,Update:LastUpdateStatus}' --output json --no-cli-pager
```

当前预期 Python 3.12、lambda_function.lambda_handler、256MB、10 秒。只选取必要字段，不整份输出可能含敏感内容的环境变量。

## 查表状态、键和容量模式

```bash
aws dynamodb describe-table --table-name cj-photo-catalog --region ap-northeast-1 --query '{Status:Table.TableStatus,Keys:Table.KeySchema,Capacity:Table.BillingModeSummary.BillingMode}' --output json --no-cli-pager
```

预期 ACTIVE、PK/SK、PAY_PER_REQUEST。这不是照片条数查询。

## 查 CloudFront 部署状态

```bash
aws cloudfront get-distribution --id E1EXJ282JJY07Q --query '{Status:Distribution.Status,Domain:Distribution.DomainName}' --output json --no-cli-pager
```

Deployed 表示该次配置已部署；不代表功能已验收。InProgress 表示配置仍在传播。

## 涉及写入的操作另行对待

BatchWriteItem 会写表；grant-photo-read.sh 会修改角色策略；grant-photo-cloudfront.sh 会添加资源调用权限。它们不是查询命令，重复执行前先核对目的和现状，不能当作“刷新”使用。出现 AccessDenied 不直接改成管理员权限；出现同名 StatementId 也不直接删除旧策略。

记命令时保留四项：用途、目标资源、是否修改、如何判断结果。公司环境使用公司批准的知识库、代码仓库或操作手册，不把凭据存进个人备忘。
