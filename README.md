# 求职网站与照片下载应用

求职方向：云与基础设施相关岗位，地点倾向札幌。

页面用 AWS 实践、业务 monitoring tool 和自然摄影，回答「我的技术实践是什么」以及「我为什么选择札幌」。默认日文，可切换中文、英文。

求职方向已放宽为云与基础设施相关岗位，不绑定某一个职位名称。需要自己改文案、换照片或调整颜色时，先看「微调指南.md」。

## 打开与修改

直接用浏览器打开 `dist/index.html` 即可查看。不需要安装依赖或编译。

- `dist/index.html`：页面内容区块与顺序。
- `dist/styles.css`：颜色、字体、布局、手机及打印样式。
- `dist/content.js`：三种语言的文字，按相同键名一一对应。
- `dist/photos.js`：首页图、相册图片路径、顺序及标题键名。
- `dist/theme.css`：常用配色、主标题字号等调整入口。
- `dist/app.js`：语言切换、手机导航与打印。
- `dist/assets/photos/`：本人提供的五张照片的网页展示副本；保留原比例和色彩风格，E 盘原图没有修改。

想先改一句话：打开 `content.js`，找到 `ja.heroCopy`，修改引号中的内容并保存，刷新浏览器。中文和英文在对应的 `zh`、`en` 段落中单独修改。`\n` 表示换行。
